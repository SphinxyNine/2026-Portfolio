## New pages

- Resources: route and placeholder are live; curated development and automation references remain to be added.
- Blog: route, placeholder, and first three planned topics are live; article content remains to be written.
- Shop: route and placeholder are live; résumé and website templates still need licenses, previews, checkout, and support details.
- Tools: useful small utilities such as a privacy-safe PDF editor.
- Playground: a typing test or another small interactive experiment.

## Integrations

- GitHub contributions: use public GitHub data and provide a useful empty/error state.
- Ask anything: design this as an opt-in assistant. Never expose a visitor's IP, ISP, or precise coordinates without informed consent. Prefer coarse location and explain why any location data is requested.
- Sound: add only after an approved audio asset exists. Start muted, require a user action to play, persist the preference, and respect reduced-motion and accessibility settings.

## Design direction

- Keep the overview compact, dark-first, and information-led, inspired by the supplied Bryl Lim reference without copying its wording or claims.
- Use Geist consistently, solid surfaces, restrained borders, and the existing light and dark themes.
- Animate Lucide icons on hover and keyboard focus. Avoid continuous motion and disable decorative movement for reduced-motion users.
